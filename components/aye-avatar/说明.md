属性                      类型                          默认值             说明
size                        Number/String           35              头像尺寸（px）
fontSize                Number                      null             自定义字体大小，不指定则自动计算
color                       String                      '#ffffff'           文字颜色
bgColor                 String                      '#1890ff'           纯色背景（当未使用渐变时生效）
gradientColors      Array/String                []                  自定义渐变色数组（如"['#ff1de9', '#ff9a9e', '#fecfef']"），也可传JSON字符串
gradientAngle       Number/String           120                  渐变角度（度）
text                        String                          ''                  显示的文字（最多9字符，自动换行）
shape                       String                      'square'            形状：'round'（圆形）或 'square'（圆角方形）
autoFontSize            Boolean                     true                是否自动适配字体大小（原 autoFit）
shadow                      Boolean                     true            是否显示阴影
bgColorIndex            Number                      null            选取内置背景颜色（0~128）
randomBgColor       Boolean                     false           是否启用随机背景（优先于 bgColorIndex，但不会覆盖自定义渐变）

注意事项

1、预设索引取值范围：0 ~ 128，超出则忽略，使用自定义或默认背景。

2、随机背景：仅在组件创建时生成一次，不会动态变化（除非组件重新创建）。

3、优先级：randomBgColor > bgColorIndex > gradientColors > bgColor。若 randomBgColor 为 true，则忽略 bgColorIndex；若 bgColorIndex 无效，则回退到自定义渐变或纯色。


======特定调整格式=======
 size="36" 时：
| 字符数 | 示例                            | 行数     |       字体大小         |
|--------|------                           |------    |---------------------|
|   1        | `张`                            | 1       |      14px                |
|   2       | `张三`                         | 1          | 12px |
|   3       | `张三丰`                      | 1          | 10px（宽度限制） |
|   4       | `张三丰啊`                   | 2(每行两个字) | 10px |
|   5       | `张三丰啊啊`                | 2         | 9px |
|   6       | `张三丰啊啊啊`             | 2         | 9px |
|   7       | `张三丰啊啊啊啊`          | 3         | 8px |
|   8       | `张三丰啊啊啊啊啊`       | 3        | 8px |
|   9       | `张三丰啊啊啊啊啊啊`    | 3        | 8px |


======关于内置色彩======
后续想删减 / 新增配色，只需修改对应 双色渐变色彩 CUSTOM_DUAL_GRADIENTS 、 三色渐变色彩 CUSTOM_TRI_GRADIENTS，不影响原有基础配色。

aye-checkbox / aye-checkbox-group 复选框组件使用文档

一、组件概述

基于 Vue3 + uni-app 封装复选框组件，分为两个文件：

  • aye-checkbox.vue：单个复选框
  • aye-checkbox-group.vue：复选框组，批量管理选中、全选、反选、禁用过滤
核心特性： 1. Group 配置自动透传给子项，子项 props 优先级更高； 2. 全选/反选自动排除 disabled 禁用选项； 3. 支持横向/竖向布局、竖向两端撑满、文字勾选框左右反转； 4. 父子组件均暴露 change 事件； 5. 最大可选数量 max 限制、形状方形/圆形、颜色尺寸自定义。

二、aye-checkbox 单个复选框

2.1 Props 属性列表

参数名 类型 默认值 说明
modelValue Boolean false 单独使用时 v-model 绑定选中状态
value String|Number|Boolean '' 在 group 组内唯一标识值
label String '' 显示文本
disabled Boolean undefined 是否禁用，优先级高于 group 全局禁用
shape String undefined square方形 / circle圆形
activeIconColor String undefined 勾选图标颜色
inactiveIconColor String undefined 未勾选边框颜色
labelColor String undefined 文字颜色
labelSize String undefined 文字字号，如 32rpx
iconSize String undefined 勾选框大小
layout String undefined horizontal横向 / vertical竖向
verticalFull Boolean undefined 竖向布局是否撑满整行两端对齐
reverseVerticalFull Boolean undefined 撑满模式是否反转：文字左、勾选框右

2.2 抛出事件 Events

事件名 参数 触发时机
update:modelValue Boolean 用于 v-model 双向绑定
change (value, checked) 点击切换选中状态；禁用不触发

2.3 独立使用示例

<aye-checkbox
  v-model="singleCheck"
  label="同意协议"
  value="agree"
  shape="circle"
  @change="handleSingleChange"
/>

const singleCheck = ref(false)
const handleSingleChange = (val, checked) => {
  console.log('当前项值：', val, '是否选中：', checked)
}

三、aye-checkbox-group 复选框组

3.1 Props 属性

参数 类型 默认值 说明
modelValue Array [] v-model 绑定选中 value 数组
max Number|String 999 最大可选数量，支持字符串传入如 max="3"
layout String horizontal horizontal横向自动换行 / vertical竖向单列
disabled Boolean false 全局全部禁用
verticalFull Boolean false 子项统一开启竖向两端撑满
reverseVerticalFull Boolean false 全局统一反转：文字居左，勾选框居右
shape/颜色/尺寸等 - - 全部自动透传给子 aye-checkbox

3.2 组组件 Events

事件 参数 触发场景
update:modelValue Array v-model 更新
change selectedList: Array 点击子项、全选、反选、清空均触发

3.3 Ref 对外暴露实例方法

// 获取组件实例
const groupRef = ref(null)

// 1. 全选（自动过滤禁用项，受max限制）
groupRef.value.selectAll(allValueArray)

// 2. 反选（仅在可用非禁用项内取反）
groupRef.value.invertSelect(allValueArray)

// 3. 清空所有选中
groupRef.value.clearAll()

3.4 完整业务调用示例

<template>
  <view style="padding:30rpx">
    <aye-checkbox-group
      v-model="checkList"
      ref="groupRef"
      layout="vertical"
      vertical-full
      :reverse-vertical-full="true"
      :max="3"
      shape="circle"
      @change="groupChange"
    >
      <aye-checkbox label="选项一" value="1" />
      <aye-checkbox label="选项二" value="2" />
      <aye-checkbox label="禁用项（全选反选跳过）" value="3" disabled />
      <aye-checkbox label="选项四" value="4" />
    </aye-checkbox-group>

    <view style="margin-top:30rpx;display:flex;gap:20rpx">
      <button @tap="$refs.groupRef.selectAll([1,2,3,4])">全选</button>
      <button @tap="$refs.groupRef.invertSelect([1,2,3,4])">反选</button>
      <button @tap="$refs.groupRef.clearAll()">清空</button>
    </view>
  </view>
</template>

<script setup>
import { ref } from 'vue'

const checkList = ref([])
const groupChange = (list) => {
  console.log('组选中变化：', list)
}
</script>

四、优先级规则（重要）

样式/禁用参数优先级： 子组件自身传入 props > Group 全局 props > 组件内部默认值

例：Group 设置 disabled=true，某个子项单独写 :disabled="false"，则该项可点击。

五、布局生效条件（竖向左右反转）

想要实现：竖向列表、整行撑开、文字在左，勾选框在右，三个属性必须同时开启：

layout="vertical"
vertical-full
:reverse-vertical-full="true"

六、全选/反选内置逻辑

  • 自动收集所有子项 value + disabled 状态，挂载注册、卸载删除；
  • 全选：只勾选非禁用条目，超出 max 自动截断；
  • 反选：禁用项完全不参与运算，只对可选项取反；
  • 单个点击本身无法触发禁用复选框。

七、版本更新说明（本次迭代点）

  1. 修复 Group layout/verticalFull/reverseVerticalFull 无法透传给子组件问题；
  2. 增加子项 disabled 状态上报，全选反选自动排除禁用项；
  3. 单个 Checkbox 和 Group 都对外暴露独立 change 事件；
  4. max 兼容字符串类型传参，不抛出校验警告；
  5. 使用 toRefs 保证全局配置响应式更新；
  6. 新增实例方法 defineExpose，支持 ref 调用全选/反选/清空。

八、注意事项

1. 放入 aye-checkbox-group 的子项必须填写唯一 value，否则选中逻辑错乱；

2. 全选/反选如果不传 allValues 数组，会自动使用组件内部收集到的有效子项列表；

3. uni-app 环境依赖 uni.showToast 做数量超限提示，H5 可自行替换 alert；

4. 组件内部使用 Vue3 composition API，仅支持 Vue3 项目。

AyeRadio 单选框组件完整使用文档

一、组件概述

基于 Vue3 + uni-app 开发，分为两个联动组件：

  • aye-radio.vue：单个单选选项，保留原始新拟态凹凸阴影UI，CSS一行未改动
  • aye-radio-group.vue：单选组容器，实现互斥单选、属性全局透传
核心特性清单 1. 完全保留原始单选圆圈新拟态阴影样式，不删减任何CSS代码； 2. Group全局配置自动下发子项，子项props优先级更高； 3. 支持禁用置灰、自定义图标大小/颜色、文字大小/颜色； 4. 横向排列 / 竖向单列排列；竖向可开启整行占满+两端对齐，支持文字左、圆点右反转布局； 5. 两个组件均对外抛出 change 事件； 6. 无需自定义形状、无需替换图标，只保留原生圆形单选圆点。

二、aye-radio 单个单选框

2.1 Props 属性列表

参数名 类型 默认值 说明
modelValue String | Number '' 组件独立使用时v-model绑定值
value String | Number 必填 当前选项唯一标识，放入group必须唯一
label String '' 单选框右侧展示文字
disabled Boolean undefined 是否禁用，优先级高于group全局禁用
iconSize String 50rpx 单选外圆整体尺寸，如 46rpx
iconActiveColor String #07c160 选中时内部圆点颜色
iconNormalColor String #9baacf 未选中内部圆点颜色
labelColor String #333 文字常规颜色
labelSize String 32rpx 文字字号大小
verticalFull Boolean undefined 竖向布局是否占满整行、两端对齐
reverseAlign Boolean undefined 竖向铺满时反转：文字居左，圆点居右

2.2 Events 抛出事件

事件名 回调参数 触发说明
update:modelValue value值 用于v-model双向绑定
change (value, true) 点击选中触发；禁用状态不执行

三、aye-radio-group 单选组容器

3.1 Props 属性

参数 类型 默认值 说明
modelValue String | Number '' v-model绑定当前选中项value
layout String horizontal 布局：horizontal横向 / vertical竖向
disabled Boolean false 整组全部禁用置灰
iconSize String '' 全局统一单选框尺寸
iconActiveColor String '' 全局选中圆点颜色
iconNormalColor String '' 全局未选中圆点颜色
labelColor String '' 全局文字颜色
labelSize String '' 全局文字大小
verticalFull Boolean false 子项默认开启竖向铺满整行
reverseAlign Boolean false 子项默认文字左、圆点右反转布局

3.2 Events 事件

事件 参数 说明
update:modelValue 选中值 双向绑定
change selectedValue 任意子项切换选中立即触发

四、优先级规则（重要）

样式/禁用权值顺序： 子组件单独传入props > Group全局props > 组件内部默认值

举例：Group设置全局disabled=true，某一个子项单独写 :disabled="false"，则该项可正常点击选择。

五、竖向左右反转布局生效条件

想要实现效果：列表竖向排布、每一项撑满整行、文字在左侧，单选圆点在最右侧，三个属性必须同时开启：

layout="vertical"
vertical-full
reverse-align

六、UI样式说明（严格保留原始代码）

  1. 单选圆圈使用新拟态浮雕阴影：未选中外凸阴影，选中内凹inset阴影；
  2. 外框50rpx、内部圆点25rpx比例固定，自定义尺寸会等比例缩放圆点；
  3. 过渡动画0.3s缓动，点击切换视觉流畅；
  4. 禁用项整体透明度降低至0.55，pointer-events禁止点击；
  5. 内部CSS变量、阴影参数、圆角全部沿用最初提供源码，无删减修改。

七、注意事项 & 避坑指南

  1. 放入 aye-radio-group 中的每一个 aye-radio 必须填写唯一 value，否则互斥逻辑失效；
  2. uni-app模板class绑定统一使用三元表达式写法，避免Vite Vue解析报错；
  3. 仅支持 Vue3 Composition API，Vue2项目无法直接使用；
  4. rpx单位为uni-app小程序适配单位，H5端自动转换；
  5. 单选本身为互斥逻辑，不提供多选、最大选择数量max参数。

八、同系列组件统一架构说明

本套Radio组件与之前AyeCheckbox复选框组件架构完全统一：

  • 父组件provide注入，子组件inject接收全局参数；
  • props优先级计算逻辑一致；
  • change事件抛出规则一致；
  • 布局参数命名规范统一（verticalFull/reverseAlign），便于团队维护记忆。

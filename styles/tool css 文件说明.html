开始 简介与引入

本类库采用 原子化 CSS 设计思路，灵感来自 TMUI CSS Tool。每个类只负责一条或一组固定的 CSS 声明，通过组合多个类完成布局，绝大多数日常界面无需再手写样式。

本文档对应 styles/tool-px.css（px 版本）。文中所有数值单位都是 px，所有示例都可直接用于 px 版本。表格中的「CSS 等价声明」一栏给出该类在样式表中的原始声明，便于精确理解其行为。

两个版本的区别

版本文件类名前缀单位适用场景
px 版（本文档）styles/tool-px.css无前缀，如 pa-20px需要固定尺寸、精确按设计稿像素还原、或与其他 px 体系混用
rpx 版styles/tool-rpx.css统一带 rpx- 前缀，如 rpx-pa-20rpx按 750rpx 设计稿自动适配不同屏宽

两个版本的类名一一对应（rpx 版仅在最前面多加 rpx-），但因为前缀不同，可以同时引入而不会互相覆盖。注意：两版的数值含义不同，例如 pa-20 是 20px，rpx-pa-20 是 20rpx，不能按同一套数值习惯书写。

引入方式

在 App.vue 的 <style> 标签中引入（路径按项目实际目录调整，本项目的目录是 styles）：

<style>
/* 引入 px 版本（本文档对应的版本） */
@import '@/styles/tool-px.css';
</style>

本项目当前 App.vue 中实际启用的是 rpx 版，要使用 px 版需要把 @import '@/styles/tool-rpx.css'; 换成上面的路径，或取消 px 版那一行注释。

引入后即可在任意组件的 class 中直接使用，例如：

<view class="flex flex-row flex-start-center pa-20 bg-white round-10 shadow-3">
  <text class="text-size-n text-weight-b">内容</text>
</view>
设计理念：命名统一，易于记忆和推断。表格中写明每一个实际存在的类，范围写法（如 0~25）均指连续整数逐一生成的类；凡是存在例外的（如内外边距只提供 2~100 的偶数档、负数从 1 开始），都在对应章节明确标出。

1 杂类

这一节只保留 CSS 文件第 1 节「杂类」中真正不便归类的 6 个类：安全区、溢出、清除浮动与鼠标指针。其余类已按用途重新归位：定位类（absolute / fixed / relative / sticky）见第 13 节，盒模型与显示、垂直对齐类见第 9 节，换行类见第 2 节，灰度滤镜见第 8 节，fulled / fulled-height 见第 16 / 17 节。

9 布局

14 外边距 (Margin)

共 7 组方向前缀。数值为 2~100 的偶数档位，步进 2px（2、4、6 … 100），不提供 0；没有负值类，也没有 4 倍档（n 系列）。每方向 50 个类，7 方向共 350 个，外加 7 个 auto。

注意 注意事项

优先级：本类库全部是单类选择器（如 .pa-20），优先级为 0,0,1,0。内联样式、!important、ID 选择器或多类组合选择器都会覆盖它。当两个工具类作用于同一属性（例如 fulled 与 w-200）时，由它们在 CSS 文件中的先后顺序决定结果，而不是你在 class 属性里的书写顺序。
项目说明
文件路径px 版文件为 styles/tool-px.css，体积约 77KB（未压缩）；rpx 版是 styles/tool-rpx.css，约 87KB。不要把本文档的 px 数值用到 rpx 版上。
两个版本共存rpx 版类名统一带 rpx- 前缀，px 版无前缀，二者可同时引入；但同一元素上不要同时写语义相同的两个版本类，避免属性互相覆盖。
px 与 rpx 的差别px 是固定像素，不随屏宽缩放；rpx 以 750 为基准按屏宽自适应。跨端适配优先选 rpx 版，需要严格固定尺寸（如 1px 细线）选 px 版。
类名冲突若与项目已有类名重名，可调整引入顺序，或改用 rpx 版前缀来规避。
性能约 77KB 未压缩，其中内外边距合计仅 707 条规则（margin 357 + padding 350），约占 26KB，是所有分区里最轻的。全部引入会增加包体，生产环境仍建议用构建工具按需提取用到的类，或按业务拆分自定义子集。
安全区safe-height 依赖 env(safe-area-inset-bottom)，需要在页面 meta 中设置 viewport-fit=cover 才会出现数值；非全面屏设备上结果为 0。
兼容提示position: sticky、Flex 容器的 gap、filter: grayscale()、-webkit-line-clamp 在较旧的 WebView / 小程序基础库中可能不生效。若目标端较旧，建议对这几类做降级处理（如用 margin 替代 gap，用固定高度 + overflow 替代 line-clamp）。
vh 单位h-screen 使用 100vh，部分小程序场景中键盘弹起或导航栏会影响其实际高度，需实测。
省略号生效条件text-overflow 与 text-overflow-{1~5} 都要求元素宽度受限；在 Flex 子项上可能还需要 flex-none 或 flex-min-w-0（即 min-width: 0）才能正常省略。

开始 简介与引入

本类库采用 原子化 CSS 设计思路，灵感来自 TMUI CSS Tool。每个类只做一件事，通过组合多个类来完成布局，无需写一行样式代码。分两个版本，一份的单位为 rpx，另一份的单位为 px。

引入方式

在 App.vue 的 <style> 标签中引入：

<style>
@import '@/css/tool.css';
</style>

引入后即可在任意组件的 class 中直接使用。

设计理念：命名规则统一，易于记忆和推断。95% 的日常布局可通过本类库完成。

12 位置控制

<view class="absolute t-24 l-n10">定位元素</view>
<view class="absolute t--20">上浮元素</view>

实战 常用组合示例

居中卡片

<view class="flex flex-center fulled" style="height:400rpx">
  <view class="bg-white round-10 shadow-5 pa-30 ma-20">
    <text class="text-size-lg text-weight-b text-align-center">标题</text>
    <text class="text-size-n text-gray mt-10">描述内容</text>
  </view>
</view>

顶部导航栏

<view class="flex flex-between bg-white pa-20 border-b">
  <text class="text-size-lg text-weight-b">返回</text>
  <text class="text-size-lg text-weight-b">标题</text>
  <text class="text-size-lg">更多</text>
</view>

三列网格布局

<view class="grid grid-col-3 gap-5 pa-20">
  <view class="bg-white round-10 shadow-3 pa-20 flex flex-center" v-for="i in 9">
    <text>项目 {{i}}</text>
  </view>
</view>

底部安全区按钮

<view class="fixed b-0 fulled bg-white pa-20">
  <view class="bg-blue round-10 flex flex-center" style="height:88rpx">
    <text class="text-white text-size-lg text-weight-b">确认</text>
  </view>
  <view class="safe-height"></view>
</view>

横向滚动标签

<view class="flex flex-row overflow-x gap-3 pa-20">
  <view class="bg-gray round-pill px-20 py-10 nowrap" v-for="tag in tags">
    <text class="text-size-s">{{tag}}</text>
  </view>
</view>

注意 注意事项

优先级：本类库为纯 CSS，优先级低于内联样式和 !important
项目说明
类名冲突如与已有样式冲突，可通过调整引入顺序解决
性能类库较大（~150KB），建议在生产环境使用构建工具进行 tree-shaking 或按需引入
平台兼容所有类均兼容 H5、小程序、APP 等多端
rpx 单位所有尺寸基于 750rpx 设计稿宽度，自动适配不同屏幕

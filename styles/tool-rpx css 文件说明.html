开始 简介与引入

本类库采用 原子化 CSS 设计思路，灵感来自 TMUI CSS Tool。每个类只负责一条或一组固定的 CSS 声明，通过组合多个类完成布局，绝大多数日常界面无需再手写样式。

本文档对应 styles/tool-rpx.css（rpx 版本）。文中所有尺寸数值单位都是 rpx，所有类名都带 rpx- 前缀；表格中的「CSS 等价声明」一栏给出该类在样式表中的原始声明，便于精确理解其行为。

两个版本的区别

版本文件类名前缀单位适用场景
rpx 版（本文档）styles/tool-rpx.css统一带 rpx-，如 rpx-pa-20rpx按 750rpx 设计稿自动适配不同屏宽，跨端适配优先
px 版styles/tool-px.css无前缀，如 pa-20px需要固定尺寸、精确按像素还原（如 1px 细线）

两个版本的类名除前缀外一一对应，但因为前缀不同，可以同时引入而不会互相覆盖。注意数值含义不同：rpx-pa-20 是 20rpx，pa-20 是 20px；字号、投影、间隙等两版的具体数值也不完全相同，请以各自文档为准。

引入方式

在 App.vue 的 <style> 标签中引入（本项目当前启用的就是这一行）：

<style>
@import '@/styles/tool-rpx.css';
</style>

引入后即可在任意组件的 class 中使用，注意必须写完整的 rpx- 前缀：

<view class="rpx-flex rpx-flex-row rpx-flex-start-center rpx-pa-20 rpx-bg-white rpx-round-10 rpx-shadow-3">
  <text class="rpx-text-size-n rpx-text-weight-b">内容</text>
</view>
设计理念：命名统一，易于记忆和推断。表格中写明每一个实际存在的类，范围写法（如 0~25）均指连续整数逐一生成的类；凡是存在例外的（如 rpx 版宽高最大到 rpx-w-750 / rpx-h-750、内外边距只提供 2~100 的偶数档、负数从 1 开始），都在对应章节明确标出。

1 杂类

这一节只保留 CSS 文件第 1 节「杂类」中真正不便归类的 6 个类：安全区、溢出、清除浮动与鼠标指针。其余类已按用途重新归位：定位类（rpx-absolute / rpx-fixed / rpx-relative / rpx-sticky）见第 13 节，盒模型与显示、垂直对齐类见第 9 节，换行类见第 2 节，灰度滤镜见第 8 节，rpx-fulled / rpx-fulled-height 见第 16 / 17 节。

类名CSS 等价声明详细说明
rpx-safe-heightheight: constant(safe-area-inset-bottom); height: env(safe-area-inset-bottom)底部安全区高度，用于适配 iPhone 底部横条。第二行会覆盖第一行：支持 env() 的端用第二行，旧版 iOS 用 constant() 兜底。通常放在页面最底部作为占位块，本身不设置宽度。
rpx-overflowoverflow: hidden横纵两个方向都裁剪溢出内容，不产生滚动条。
rpx-overflow-xoverflow-x: hidden; overflow-y: auto横向溢出隐藏、纵向溢出时自动滚动。类名虽叫 x，实际是把 x 方向锁死、放开 y 方向滚动。
rpx-overflow-yoverflow-y: hidden; overflow-x: auto纵向溢出隐藏、横向溢出时自动滚动，常用于横向滑动标签栏。
rpx-clear.rpx-clear::after { content: ''; display: table; clear: both }通过 ::after 伪元素清除浮动，写在浮动元素的父容器上。注意它作用的是伪元素，不是元素本身。
rpx-pointercursor: pointer鼠标悬停显示手型指针，用于提示可点击。
按用途归位：本节原先承载的基础类已按功能拆分到对应章节，均为真实存在的独立类，可通过本节开头的说明或侧边栏搜索快速找到。

换行控制（rpx-wrap / rpx-nowrap）

这两个类控制文本是否允许换行，原本归在杂类，现按用途移入文本类。注意 rpx-nowrap 不只是设置 white-space，还带有 display: inline。

类名CSS 等价声明详细说明
rpx-wrapword-wrap: break-word; word-break: break-all; white-space: normal允许强制断行：长英文单词、连续数字、URL 都会换行，同时把 white-space 恢复为 normal。
rpx-nowrapwhite-space: nowrap; display: inline禁止换行。注意它同时把元素改成 display: inline，可能导致宽高设置失效。若需要保持块级显示，叠加第 9 节的 rpx-d-block 是无效的：rpx-d-block 在 CSS 文件中位于 rpx-nowrap 之前，会被后者覆盖，请改用内联样式重置。

14 外边距 (Margin)

共 7 组方向前缀。数值为 2~100 的偶数档位，步进 2rpx（2、4、6 … 100），不提供 0；没有负值类，也没有 4 倍档（n 系列）。每方向 50 个类，7 方向共 350 个，外加 7 个 auto。

注意 注意事项

优先级：本类库全部是单类选择器（如 .rpx-pa-20），优先级为 0,0,1,0。内联样式、!important、ID 选择器或多类组合选择器都会覆盖它。当两个工具类作用于同一属性（例如 rpx-fulled 与 rpx-w-200）时，由它们在 CSS 文件中的先后顺序决定结果，而不是 class 属性里的书写顺序。
项目说明
文件路径rpx 版文件为 styles/tool-rpx.css，体积约 87KB（未压缩）；px 版是 styles/tool-px.css，约 77KB。不要把本文档的 rpx 数值用到 px 版上。
两个版本共存rpx 版类名统一带 rpx- 前缀，px 版无前缀，二者可同时引入；但同一元素上不要同时写语义相同的两个版本类。
rpx 单位所有尺寸基于 750rpx 设计稿宽度，uni-app 按屏幕宽度自动换算；字号为 20~48rpx，gap 为 N×2rpx，宽高最大 750rpx，这些都与 px 版不同。
类名冲突若与项目已有类名重名，可调整引入顺序，或改用 px 版（无前缀）规避。
性能约 87KB 未压缩，其中内外边距合计仅 707 条规则（margin 357 + padding 350），约占 30KB，是所有分区里最轻的。生产环境仍建议用构建工具按需提取用到的类，或按业务拆分自定义子集。
安全区rpx-safe-height 依赖 env(safe-area-inset-bottom)，需要在页面 meta 中设置 viewport-fit=cover 才会出现数值；非全面屏设备上结果为 0。
兼容提示position: sticky、Flex 容器的 gap、filter: grayscale()、-webkit-line-clamp 在较旧的 WebView / 小程序基础库中可能不生效，建议做降级处理。
vh 单位rpx-h-screen 使用 100vh，部分小程序场景中键盘弹起或导航栏会影响其实际高度，需实测。
省略号生效条件rpx-text-overflow 与 rpx-text-overflow-{1~5} 都要求元素宽度受限；在 Flex 子项上可能还需要 rpx-flex-none 或 rpx-flex-min-w-0（即 min-width: 0）。
